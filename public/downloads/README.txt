SUTRA IDE — Windows Setup
=========================

WHAT THIS IS
A complete, installable copy of SUTRA IDE for Windows 10/11.

INSTALL (Option A — recommended)
1. Extract this ZIP anywhere (e.g. C:\SUTRA).
2. Double-click SUTRA-Setup.bat.
   - Installs dependencies (first run only, needs internet)
   - Creates a desktop shortcut with the SUTRA icon
   - Launches the IDE

INSTALL (Option B — launcher)
1. Extract this ZIP anywhere.
2. Double-click SUTRA-IDE.exe to start the IDE and open it in your browser.

REQUIREMENTS
- Node.js 20 or newer (https://nodejs.org)
- ~600 MB disk space for dependencies

NOTES
- Your API keys and cookies never leave this machine.
- The IDE runs at http://localhost:3001
